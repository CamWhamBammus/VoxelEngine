# GameEngine1

A C++ OpenGL project built from scratch to learn graphics programming and game engine development.

## Current Features

- GLFW window creation
- OpenGL 3.3 Core Profile context
- GLAD function loading
- Vertex Buffer Object setup
- Vertex and fragment shader setup
- Basic vertex attribute configuration

## Tech Stack

- C++
- OpenGL
- GLFW
- GLAD
- CMake

## Project Goals

The goal of this project is to learn how a game engine and graphics pipeline work at a low level rather than relying on an existing engine.

Planned topics include:

- Rendering triangles and meshes
- Shader management
- Vertex Array Objects
- Textures
- Transformations
- Camera systems
- Lighting
- Input handling
- Engine architecture
